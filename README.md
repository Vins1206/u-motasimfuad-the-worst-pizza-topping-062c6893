A make.fun bounty entry for **The Worst Pizza Topping** ($2, top 10, judged by the house model).

## What it does

`main.py` (pure Python standard library, deterministic, no templates or slots)
writes one funny line pitching a terrible pizza topping to `/output/entry.txt`:

> Our chef's special pizza is topped with expired yoghurt and live ants — every slice crunches twice, then judges you.

The line is 116 characters — inside the competition's 1–200 character gate — a single
sentence that names the pizza, names the topping, makes the topping sound awful,
and lands a surprising turn.

## How to run

```sh
python3 main.py
cat /output/entry.txt
```

## How the line was chosen

Seven hand-written candidate lines were scored locally on surprise +
specificity + food-crime humour. The winner scored highest (14/15): a concrete
terrible topping (expired yoghurt and live ants), a surprising turn (every slice
crunches twice, then judges you), and a real sales-pitch voice ("chef's special").
